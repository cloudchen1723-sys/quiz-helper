# 自选内嵌题库目录 (Built-in JSON Banks)

您可以在此目录下放入任意数量的 `.json` 题库文件。
项目会自动扫描此目录下的所有 `.json` 文件，并自动在应用中作为**内嵌题库**展示供用户选用。

---

### 1. 文件命名规则
- 文件名将直接作为**默认题库名称**。
- 例如：`计算机网络与核心协议速记.json`、`2024软考系统分析师真题.json`。

---

### 2. 标准 JSON 格式结构
每个 `.json` 文件的内容必须为题目对象数组 `[]`，示例：

```json
[
  {
    "id": 1,
    "type": "single",
    "question": "计算机能够直接执行的是（ ）程序。",
    "options": {
      "A": "汇编语言程序",
      "B": "高级语言程序",
      "C": "自然语言程序",
      "D": "机器语言程序"
    },
    "answer": "D",
    "analysis": "计算机的CPU只能识别和执行由0和1组成的机器语言指令，因此机器语言程序是计算机唯一能够直接执行的程序。"
  },
  {
    "id": 2,
    "type": "multiple",
    "question": "下列属于TCP/IP模型中传输层协议的有（ ）。",
    "options": {
      "A": "TCP",
      "B": "UDP",
      "C": "IP",
      "D": "HTTP"
    },
    "answer": ["A", "B"],
    "analysis": "TCP和UDP是传输层核心协议；IP属于网络层；HTTP属于应用层。"
  },
  {
    "id": 3,
    "type": "judge",
    "question": "RAM在断电后其中存储的数据依然可以完整保留。",
    "options": {
      "A": "正确",
      "B": "错误"
    },
    "answer": "B",
    "analysis": "RAM属于易失性存储器，断电后数据会立即丢失。"
  }
]
```

---

### 3. 字段说明
- `id` (数字, 必填): 题目序号，如 1, 2, 3...
- `type` (字符串, 必填): 题型，支持 `"single"` (单选), `"multiple"` (多选), `"judge"` (判断)。
- `question` (字符串, 必填): 题目题干。
- `options` (键值对象, 必填): 选项映射，如 `{"A": "选项1", "B": "选项2", ...}`。
- `answer` (字符串或数组, 必填): 
  - 单选/判断：填 `"A"` 或 `"B"` 等单个字母。
  - 多选：填数组 `["A", "B"]` 或连写字符串 `"AB"`。
- `analysis` (字符串, 选填): 考点详细解析。
