# 📚 刷题小助手 (Quiz & Study Assistant)

> 专为零基础跨学科快速建立专业名词认知与高效备考打造的轻量级刷题与速记工作台。

---

## ✨ 核心特性

- 🚀 **双重认知模式**
  - **常规做题自测**：隐藏答案，作答后即时判定对错、展示考点解析，答错自动收录至专属错题本。
  - **速记背题模式 (Flashcard)**：直接高亮展示正确答案与解析，适合新学科知识点与专业术语的快速记忆与扫盲。

- 📥 **智能题库导入与管理**
  - **纯文本智能解析**：直接粘贴 Word / 网页题目文本，智能识别单选、多选、判断题，自动提取选项、答案及解析。
  - **JSON 格式导入 / 导出**：支持标准 JSON 题库的批量导入、导出备份与跨设备迁移。
  - **多题库隔离与统计**：支持管理多个独立题库，实时统计各题型占比及掌握进度。

- 🎯 **灵活的出题与筛选策略**
  - **全量刷题**：按序刷完全库所有题目。
  - **专属错题攻克**：针对错题本中的薄弱知识点反复重练，直到完全掌握并消灭。
  - **自定义题号范围**：支持分章节或分批次练习（如 1~50 题）。
  - **模拟组卷**：按题型（单选、多选、判断）自定义抽取题量生成随机练习套卷。

- ⚡ **极致提效与键盘盲打支持**
  - 支持键盘快捷键快速作答：
    - `A` / `B` / `C` / `D`：快速选择对应选项
    - `Enter` / `Space`：确认提交或进入下一题
    - `←` / `→`：快速切换上一题 / 下一题
  - 辅助设置：支持**乱序抽题**、**计时器**与**答对 0.7s 自动切题**。
  - 答题卡概览：实时查看作答进度、正确/错误分布，支持点击任意题号直接跳转。

- 🔍 **沉浸式题库全览**
  - 专属吸顶导航与快速启动。
  - 关键词即时搜索、多维度题型筛选、错题标记过滤。

- 🔒 **本地离线与数据隐私**
  - 所有题库、练习进度与错题记录均安全存储在浏览器本地（IndexedDB / LocalStorage），无需注册登录，离线即用，保护个人数据隐私。

## 🛠️ 技术栈

- **前端框架**：[React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **构建工具**：[Vite 6](https://vitejs.dev/)
- **样式方案**：[Tailwind CSS v4](https://tailwindcss.com/)
- **图标系统**：[Lucide React](https://lucide.dev/)
- **本地存储**：IndexedDB + LocalStorage
- **交互动效**：`canvas-confetti` + 原生 CSS 关键帧过渡

## 🚀 快速开始

### 1. 克隆仓库
```bash
git clone https://github.com/your-username/quiz-study-assistant.git
cd quiz-study-assistant
```

### 2. 安装依赖
```bash
npm install
# 或者使用 pnpm / yarn / bun
```

### 3. 启动开发服务器
```bash
npm run dev
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000) 即可开始使用。

### 4. 构建生产版本
```bash
npm run build
```
打包后的静态文件将生成在 `dist` 目录中，可直接部署至任何静态托管平台（GitHub Pages、Vercel、Netlify、Cloudflare Pages 等）。

## 📋 题库导入格式说明

### 1. 纯文本一键导入示例
支持将以下格式的纯文本直接粘贴至导入弹窗中：

```text
1. 计算机网络的拓扑结构主要取决于它的（ ）。
A. 路由器
B. 资源子网
C. 通信子网
D. FDDI网
答案：C
解析：通信子网的拓扑结构往往决定了整个计算机网络的拓扑结构。

2. 以下属于操作系统的主要功能的是（ ）。【多选】
A. 处理器管理
B. 存储器管理
C. 设备管理
D. 文件管理
答案：ABCD
解析：现代操作系统主要具备处理器管理、存储管理、设备管理、文件管理和提供用户接口等功能。

3. HTTP 协议默认使用的端口号是 80。（ ）
答案：正确
解析：HTTP 默认使用 TCP 80 端口，HTTPS 默认使用 TCP 443 端口。
```

### 2. 标准 JSON 格式示例
```json
[
  {
    "id": 1,
    "type": "single",
    "stem": "计算机网络的拓扑结构主要取决于它的（ ）。",
    "options": [
      "A. 路由器",
      "B. 资源子网",
      "C. 通信子网",
      "D. FDDI网"
    ],
    "answer": "C",
    "analysis": "通信子网的拓扑结构往往决定了整个计算机网络的拓扑结构。"
  }
]
```

## ⌨️ 快捷键指南

| 按键 | 功能说明 |
| :--- | :--- |
| `A` / `B` / `C` / `D` | 快速选择对应选项（多选可连按组合） |
| `Enter` / `Space` | 提交多选题答案 / 切换至下一题 |
| `←` (方向左键) | 切换到上一题 |
| `→` (方向右键) | 切换到下一题 |
